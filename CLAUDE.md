# Galash project notes (for Claude)

Quick orientation for future Claude sessions on this repo. Long-form docs
live in `README.md`, `EXPERIMENTS.md`, `all_results.md`. This file is just
the operational shorthand.

## What the codebase does

A change-detection model = frozen vision backbone (DINOv2/v3 or SAM2.1
image encoder) + `CrossChangeAttention` + `Bridge v2` + SAM2.1 mask decoder.
Trainable params are ~13–35 M depending on whether `--finetune_decoder` is
on. Dataset I/O via `dataset.py`; model registry in `model.py`
(`ENCODERS`, `DECODERS`).

## Default training recipe (this is the "max push" recipe)

```
ENCODER=<...>  DECODER=sam2_large
EXTRA="--no_amp --no_early_stop --ema 0.99 --cnn_skip --finetune_decoder --search_threshold"
CONFIG=configs/datasets/<ds>[_heavy].yaml   # heavy yamls for 256/512² only
```

`--no_amp` is non-negotiable for dinov3 (BCE NaN at epoch 1 otherwise) and
applied to all other backbones for fairness. Wall-time cost: ~30–50 % vs
AMP, F1 delta usually within ±0.2 pp.

## Where to launch sweeps

- `slurm/launch_max_sam2.sh` — sam2_enc_large × 6 datasets on dgx
- `slurm/launch_max_dinov2.sh` — dinov2_base × 6 datasets on dgx
- `slurm/launch_max_dinov3.sh` — dinov3_base × 6 datasets on dgx
- `slurm/train.sbatch` — generic single-job sbatch wrapper (env-driven)

DGX has 8× B200 (183 GB each); each launcher submits 6 jobs and lets SLURM
queue overflow. `train.sbatch` already exports `PYTHONUNBUFFERED=1` so
`.out` files show progress live.

## Where to look at results

- `runs/<run_name>/<timestamp>/log.csv` — **source of truth** per epoch
  (val/test F1 columns). Flushed every epoch.
- `runs/<run_name>/<timestamp>/test_results.json` — final TTA test result
  (written once training completes).
- `backbone.md` — per-dataset cross-backbone summary, regenerated by
  `scripts/update_backbone_md.py` (auto-discovers any `runs/max<tag>_*`).
- `scripts/watch_sweep.sh` — terminal snapshot; pass `JOBS="..."` env. Calls
  `update_backbone_md.py` as a side effect.

## Failure-mode shortlist

- **`.out` looks frozen for many epochs**: NOT a hang. sbatch redirects
  stdout to a file → Python block-buffers in 4 KB chunks. `log.csv` is the
  truth source. (Mitigation already in `slurm/train.sbatch`:
  `export PYTHONUNBUFFERED=1`.)
- **CUDA assert in BCE / `input_val >= zero`**: gradient explosion under
  autocast. Add `--no_amp`. Already in all `launch_max_*.sh` launchers.
- **HuggingFace 404 on encoder name**: encoder registry uses
  `sam2_enc_<variant>`, decoder uses `sam2_<variant>`. Don't pass
  `sam2_base_plus` as an encoder.

## Fair-SOTA bars (no extra CD data, no synthetic, no joint training)

Hardcoded in `scripts/update_backbone_md.py` and `scripts/watch_sweep.sh`.
Rationale: SChanger / UniChange / ChangeStar+Changen all use extra
labelled CD data or synthetic pairs, so they're excluded from the
comparison the paper makes.
